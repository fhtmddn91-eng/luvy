# 어드민·매장 UX 4건 (묶음 A) — 설계

2026-09-05. 운영자 요청서 4·5·6·7번. 회원 등급·포인트(1·2·3번)는 별도 설계.

## 4. 공지 팝업 — 메인 진입 시 큰 창으로

**문제**: 메인 하단의 공지 스트립(`NoticeStrip`)은 한 줄 요약이라 눈에 안 띈다.

**설계**
- `Notice` 에 `popup Boolean @default(false)` 추가 (마이그레이션 1건).
- 어드민 공지 폼에 「메인 팝업으로 띄우기」 체크박스. 목록에는 「팝업」 배지.
- 매장 홈(`(shop)/(gated)/page.tsx`)에서 `active && popup` 인 공지를 `sortOrder` 순으로
  읽어 `NoticePopup`(클라이언트) 에 넘긴다. 없으면 아무것도 그리지 않는다.
- 팝업은 화면 가운데 모달 1개. 여럿이면 한 창 안에 세로로 나열(태그 · 제목 · 본문
  `whitespace-pre-line`, 본문이 있으면 「자세히 보기」 → `/support/notice/[id]`).
  창 안은 스크롤, 배경 어둡게, ESC · 바깥 클릭 · 닫기 버튼으로 닫는다.
- 「오늘 하루 보지 않기」: `localStorage["luvy.noticePopup.hideUntil"]` 에 다음 날 0시
  (로컬)를 기록. 읽기·쓰기는 try/catch (시크릿 창·차단 환경에서 페이지가 죽지 않게).
- 열려 있는 동안 `body` 스크롤 잠금. 스트립은 그대로 둔다(팝업 닫은 뒤에도 보이는 자리).

**하지 않는 것**: 노출 기간 예약, 팝업 위치·크기 지정, 공지별 개별 숨김.

## 5. 상품 저장 후 목록 페이지 유지

**문제**: 목록 5페이지에서 상품을 열어 저장하면 `updateProduct` 가 무조건
`/admin/products` 로 보내 1페이지로 떨어진다.

**설계**
- 목록의 상품 링크에 현재 목록 주소(`page·per·q` 가 붙은 `/admin/products?...`)를
  `?back=` 으로 실어 보낸다.
- 수정 페이지가 `back` 을 읽어 `ProductForm` 에 넘기고, 폼은 hidden `back` 으로 제출.
  폼 하단 「취소」 링크도 같은 주소로.
- `updateProduct` 는 `back` 을 `safeAdminReturnPath(raw)` 로 거른 뒤 그리로 redirect.
  허용 규칙: `/admin/products` 로 시작하는 **상대 경로**만(`//` 나 `http` 로 시작하면
  거부, 개행·제어문자 거부). 통과 못 하면 `/admin/products`. 순수 함수 + 단위 테스트.
- 신규 등록(`createProduct`)은 지금처럼 등록된 상품 화면으로 간다.

## 6. 검색창 밑 카테고리 줄 삭제

- `SearchBar` 의 대분류 바로가기 `nav` 와 오른쪽 페이드를 지우고 `categories` prop 을 없앤다.
- `Header` 는 `getTopCategories` 호출을 뺀다.
- 「전체 카테고리」 메가메뉴(`Gnb`/`CategoryMenu`)와 홈 카테고리 기둥은 그대로 —
  모바일에서도 카테고리로 가는 길이 남는다.

## 7. 추가 카테고리 — 대분류 접이식

**문제**: 대분류마다 세부 체크박스가 한 줄에 가로로 늘어서 13px 로 빽빽하다.

**설계**
- `ProductForm` 의 「추가로 노출할 카테고리」를 대분류별 접이식으로 바꾼다.
  대분류 이름 버튼(15px, 대표 카테고리 select 와 같은 높이)을 세로로 나열, 누르면
  바로 아래에 「(전체)」+ 세부 체크박스가 15px 로 2~3열 펼쳐진다.
- 접혀 있어도 선택 상태가 보이게 대분류 버튼 오른쪽에 「n개 선택」 배지.
- 대표 카테고리가 속한 대분류는 처음부터 펼친다. 대표 카테고리를 바꾸면 그 대분류를 펼친다.
- 대표 카테고리 자신은 지금처럼 목록에서 뺀다(자동 포함). 제출 값(`extraCategories`)은 변경 없음.
- 열림 상태는 컴포넌트 state (저장 안 함).

## 테스트
- `safeAdminReturnPath` 단위 테스트(허용·거부 사례).
- 공지 팝업 「오늘 하루」 만료 계산은 순수 함수로 떼어 테스트.
- 나머지는 브라우저 미리보기로 확인.
